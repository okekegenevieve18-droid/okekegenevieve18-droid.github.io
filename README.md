# Chiomaricha Genevieve Okeke — Data Analyst Portfolio

A static, responsive portfolio website for **Chiomaricha Genevieve Okeke**, positioned around Data Analysis, Business Intelligence, and Market Research.

## Run locally

From this directory, start a static server:

```bash
python -m http.server 4173 --bind 0.0.0.0
```

Then open the local preview supplied by the development environment.

## Structure

- `index.html` — semantic page structure and verified portfolio content
- `styles.css` — responsive visual system and layout
- `script.js` — mobile navigation, project filtering, lightbox, and reveal enhancement
- `assets/Chiomaricha-Genevieve-Okeke-CV.pdf` — sanitized downloadable CV without a phone-number field
- `assets/profile-portrait.png` — cropped portrait supplied for the recruiter-facing hero
- `assets/projects/` — supplied project dashboard screenshots
- `BUILD_PROMPT.md` — complete build brief, source-of-truth rules, and QA checklist

## Content rules

The site uses only verified portfolio information. Missing facts are labelled `Not provided`, `Not available`, or `Pending/not yet released`. No phone number, fabricated metrics, unverified dashboard URL, private source filename, contributor name, internal team reference, or restricted organization detail is included.
